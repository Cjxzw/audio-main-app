# 高级 TTS 导演

本 Skill 仅在当前用户回合生效。普通回复继续使用 App 自动 TTS，不要调用隐藏工具。

需要高级讲话时输出以下结构化调用，正文必须为空：

```json
{"name":"voice_reply","arguments":{"text":"完整待播正文","mode":"preset","voice":"茉莉","style_prompt":"角色、场景、语速、气息、停顿、重音和情绪弧线"}}
```

`mode` 可为 `preset` 或 `design`。`preset` 的 `voice` 只允许冰糖、茉莉、苏打、白桦；原创音色使用 `design`，传 `voice_prompt` 且不传 `voice` 或 `style_prompt`。局部情绪和动作标签直接放在 `text` 对应语句前。当前不支持音色克隆，也不通过本 Skill 唱歌。

## 使用边界

- 用户没有明确提出音色、角色、方言、场景或情绪表演要求时，不使用本 Skill。
- 不擅自添加剧情、人设或情绪，不得模仿真实人物身份或声称完成音色克隆。
- `voice_reply` 是终止型隐藏工具，必须单独调用；全部最终回复放入 `text`，普通正文为空。
- `preset` 用于预置音色上的角色、方言、语速、气息、停顿、重音和情绪变化。
- `design` 只用于用户明确要求临时创造新音色，不等同于导演模式，也不支持样本复刻。

## 参数

- `text`：完整待播正文。整体风格标签放在开头，局部变化标签紧邻对应语句。
- `mode`：`preset` 或 `design`。
- `voice`：`preset` 必填，只允许冰糖、茉莉、苏打、白桦。
- `style_prompt`：`preset` 可选，描述角色、场景和演绎指导。
- `voice_prompt`：`design` 必填，使用 1 至 4 句描述年龄感、音高、音色、语速、口音、气息和气质。

`preset` 的 `style_prompt` 建议按以下结构组织：

```text
【角色】身份、性格底色、关系位置和说话习惯。
【场景】时间、地点、事件、对象和当前情绪位置。
【指导】基础声线、语速、气息、停顿、重音、共鸣、咬字、情绪弧线及禁止事项。
```

可在 `text` 中使用半角括号、全角括号或方括号编写短标签，例如：`（压低声音，极轻气声）我从未怪过你。` 标签描述接下来如何发声，不是需要朗读的舞台说明；只在表演发生变化时插入，避免互相矛盾或每句重复。

示例：

```json
{"name":"voice_reply","arguments":{"text":"(紧张 忐忑)（深呼吸）冷静，不就是一次面试吗。","mode":"preset","voice":"苏打","style_prompt":"【角色】第一次参加重要面试的年轻人。\n【场景】面试室门外等待叫号。\n【指导】开头呼吸不稳，随后加快语速自我安慰；不要演成夸张喜剧。"}}
```
